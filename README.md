**VEGA Harness** — открытая среда для ИИ-агентов на базе [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Дайте агенту задачу и рабочую папку: он сможет изучать материалы, редактировать файлы, выполнять команды и искать информацию в интернете. Вы видите ход работы, вызовы инструментов и результат в одной сессии.

<a id="capabilities"></a>

## Одна сессия. От исследования до готовых файлов.

| | Что получает ваша задача |
|---|---|
| 🛠️ **Работа с проектом** | Чтение и редактирование файлов, команды в терминале, запуск тестов. Агент работает с содержимым вашей рабочей папки. |
| 🔎 **Поиск с источниками** | Поиск в интернете и чтение страниц через VEGA. Можно запросить ссылки, сравнение решений и проверку фактов. |
| 🧠 **Выбор моделей** | Вход через аккаунт VEGA и каталог доступных ему моделей. Выбирайте модель под задачу через интерфейс. |
| 🛡️ **PII shield** | Опциональное обезличивание запросов на стороне VEGA. Включается отдельно; по умолчанию выключено. [Как устроено](packages/llm/llm-vega-account/README.md). |
| ⏰ **Задачи по расписанию** | Повторяющиеся поручения и запланированные продолжения работы. [Возможности и условия](packages/schedule/README.md). |
| 🧩 **Расширение под себя** | Подключайте инструменты, MCP-серверы и skills, в том числе VEGA Studio для генерации изображений и видео. Доступность зависит от установленных расширений и их настройки. |

### Начните с задачи, которую давно откладывали

Примеры запросов для выбранной рабочей папки:

**Код → изменения и проверка**

> «Изучи проект, найди причину ошибки, предложи исправление и запусти подходящие тесты».

**Источники → обоснованное решение**

> «Сравни три решения для нашего проекта. Найди актуальную документацию, добавь ссылки и сохрани выводы в Markdown».

**Документы → готовый материал**

> «Прочитай материалы в этой папке и подготовь краткий отчёт: главное, открытые вопросы и следующие шаги».

**Идея → медиа** · с настроенным VEGA Studio skill

> «Подготовь иллюстрацию и короткий видеоролик для этой статьи. Сохрани результаты в папку проекта».

## Ваша первая задача

Для запуска из исходников нужны **Node.js ≥ 24.9** и **pnpm**; версия pnpm закреплена в [package.json](package.json). Скачайте этот репозиторий и откройте терминал в его корне:

```sh
pnpm install
pnpm run build
pnpm dsh web
```

1. **Откройте Web UI** по адресу, который напечатает команда; по умолчанию — `http://127.0.0.1:3080`.
2. **Войдите в аккаунт VEGA.** Приложение получит управляемый API-ключ и загрузит доступные модели; копировать ключ вручную не нужно.
3. **Выберите рабочую папку и модель.** Создайте сессию и отправьте первую задачу.

> **Developer preview.** Возможны ломающие изменения. Перед запуском прочитайте [уведомление о безопасности](SAFETY.md); доступ к файлам и командам определяется активной политикой разрешений.

## Соберите агента под свой процесс

В основе — **«всё — плагин»** на Cordis. Адаптеры моделей, инструменты, хранение сессий, песочница и цикл агента подключаются через конфигурацию. Можно менять состав агента и развивать свои расширения.

Сессии сохраняют историю работы и вызовы инструментов, поддерживают продолжение после перезапуска и сжатие контекста. Подробности — в [архитектуре](docs/architecture.md).
