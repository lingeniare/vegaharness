# Журнал изменений VEGA Harness

## 0.2.5 — синхронизация с upstream (23.11.2026)

Слит `deepseek-ai/deepseek-harness` master (коммит `4b399c39`) — релизы
`0.2.3-alpha.1` и `0.2.3-alpha.2`, vendored Cordis `4.2.0-alpha.1` и все
исправления, вышедшие после релиза. Всего 1753 коммита upstream:
180 новых возможностей, 326 исправлений, 136 рефакторингов, 15 оптимизаций.

### Новое из upstream

**Аккаунт и интеграции**

- OAuth-авторизация: гранты, пассивное обновление токенов, повторная
  авторизация и выход без разрыва соединения.
- Страница «Плагины»: подключение аккаунтов коннекторов, настройки плагинов,
  фирменные иконки, локализация на все поставляемые языки.
- Новые интеграции через общий MCP-менеджер и CLI-киты: Notion, Linear,
  Feishu (lark-cli), WeCom, DingTalk, Tencent Docs, Tencent Meeting.
- MCP-инструменты загружаются по требованию на агента через лоадер на сервер.

**Сессии и рабочая область**

- Плавающая Session-панель: change requests, фоновые задачи и сабагенты
  переехали в неё; сворачивание длинных списков, меню строк, поиск.
- Session workspace roots с привязанным переносом; read-only инструменты
  просмотра workspace и списка сессий.
- Worktree: `enter_worktree` для существующих worktree, именование веток,
  старт от remote-веток, индикация чтения изменений.
- Persistent-in-memory режим выполнения по умолчанию (scoped REPL).
- SQLite-хранилище сессий с импортом legacy JSONL при открытии.
- История промптов по ArrowUp/ArrowDown, слот плейсхолдера в композере.

**Code review**

- Страница код-ревью, компактный список ревью, скелетоны при загрузке,
  цитирование комментариев ревью в чат.
- Чтение, ревью и привязка GitLab merge requests; список своих CR.

**Desktop / Windows**

- «Настройки» в меню приложения.
- Windows x64: скачивание и запуск dws/lark-cli/wecom-cli/tmeet по
  абсолютным путям из runtime-контекста.
- Поддержка Windows pre-login packaging runners и сводка параметров
  упаковки.

**Прочее**

- Переключатель `safetyCheck` — контентная проверка DeepSeek; по умолчанию
  проверка запрашивается всегда.
- Плагинам доступна версия работающего DSH.
- Инспекция результатов инструментов по отрендеренному тексту; полные
  аргументы вызовов на карточках инструментов.
- Office: единый office-скилл (форматные руководства читаются по
  требованию), новый office-pdf, pypdf во встроенном Python.
- Action cards из блоков ответа вместо отдельного инструмента; hover-карточки;
  marquee заголовков панели; перетаскивание секций и сессий.

### Исправления

326 upstream-фиксов. Наиболее затронутые области: web (38), forge (26),
desktop (22), client (20), session (16), computer-use (16), панель (15),
сабагенты (14), Feishu (8), remote-connection (7), PTC (7), задачи (6),
Python SDK (5).

### Изменения форка VEGA

- Сохранены брендинг VEGA, продуктовые локали en/ru и endpoint
  `api.vega.chat` (OpenRouter-совместимый прокси).
- Канал обновлений — только stable; upstream-переключатель nightly/stable
  намеренно не возвращён.
- Версия поднята до `0.2.5`; upstream-манифесты `0.2.3-alpha.2` приведены
  к `0.2.5` (benchmark остаётся `0.1.3-alpha.1`).
- Upstream `deepseek-auth` согласован с реализацией аккаунта форка в
  `packages/credentials` (добавлен `ru_RU` в `PlatformLocale`).
- Исправлены регрессии мёрджа: повреждённые фикстуры и локали, имена
  артефактов сборки, потерянные записи каталога плагинов
  (`tool-working-directory`, `action-cards`), параметр `revision` в
  загрузке обновлений desktop.
